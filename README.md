# KBL Electronics

KBL Electronics is an e-commerce platform built with React 19, Tailwind CSS, Vite, and Firebase.

## Status
- **Payments:** Not yet implemented (mock checkout).
- **Security:** Firestore rules and advanced data security hardening are not yet implemented.

## Tech Stack
- Frontend: React 19, React Router v7, Tailwind CSS v4, Framer Motion, TanStack Query.
- Backend: Express, Node.js (compiled via esbuild for production).
- Database & Auth: Firebase Auth, Firestore.
- Tests: Vitest and Testing Library.
